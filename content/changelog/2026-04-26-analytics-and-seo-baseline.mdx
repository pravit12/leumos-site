Two things had to be true before we shipped any real surface:

1. We could measure traffic without dropping a cookie banner on visitors.
2. Search engines could crawl, index, and link us correctly from the first page that lives at a real URL.

What landed:

- **Plausible** for privacy-first analytics — no cookies, no banner.
- **Microsoft Clarity** for free session recordings and heatmaps, gated on `NEXT_PUBLIC_CLARITY_PROJECT_ID` so previews stay quiet.
- **Google Search Console** and **Bing Webmaster Tools** verification through site-verification meta tags driven by env vars.
- A `sitemap.xml` and `robots.txt` that disallow indexing on Vercel preview deploys and allow it everywhere else.
- A canonical URL helper (`getSiteUrl`) so every page declares the same origin in metadata, OG tags, and structured data.

This is plumbing, not a product. It's here so the next thing we ship can be measured and crawled the day it goes live.
